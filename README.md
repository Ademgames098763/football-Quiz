# ⚽ Football Quiz App

تطبيق اختبار معلومات كرة القدم باستخدام الذكاء الاصطناعي (Gemini API).

## 🚀 كيفية التشغيل

1. افتح ملف `index.html` في المتصفح
2. أدخل مفتاح Gemini API الخاص بك في الحقل المخصص
3. اختر مستوى الصعوبة وابدأ الاختبار!

## 🔑 الحصول على مفتاح API

1. اذهب إلى [Google AI Studio](https://makersuite.google.com/app/apikey)
2. سجل الدخول بحساب Google الخاص بك
3. أنشئ مفتاح API جديد
4. انسخ المفتاح واستخدمه في التطبيق

## ⚠️ ملاحظات أمنية

- **لا تشارك** مفتاح API الخاص بك مع أي شخص
- **لا ترفع** مفتاح API إلى GitHub أو أي مستودع عام
- المفتاح يُحفظ محلياً في متصفحك فقط (localStorage)

## 📁 هيكل المشروع

```
foot/
├── index.html      # الصفحة الرئيسية
├── app.js          # منطق التطبيق
├── styles.css      # التنسيقات
├── logo.png        # شعار التطبيق
├── .env.example    # نموذج ملف البيئة
├── .gitignore      # ملفات مستبعدة من Git
└── README.md       # هذا الملف
```

## 🛡️ للمطورين

إذا كنت تريد تطوير المشروع:

1. انسخ `.env.example` إلى `.env`
2. أضف مفتاح API الخاص بك في ملف `.env`
3. تأكد من أن `.gitignore` يستبعد ملف `.env`
